# homebrew-secretx

Homebrew tap for the [SecretX](https://github.com/TimMikeladze/secretx) menu bar app — the SecretX dashboard in your macOS menu bar, for cloud and self-hosted servers.

```bash
brew install --cask timmikeladze/secretx/secretx
```

The app updates itself; `brew upgrade` leaves it alone (`auto_updates true`). The cask is updated by SecretX's release workflow.
